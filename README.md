# 掘進管理システム 修正版

## 修正内容
- 入力値・数値が保存されない問題を修正
- 入力値が印刷に反映されない問題を修正
- 印刷様式記入欄を保存し、印刷へ反映
- 現場追加APIと画面処理を修正
- 元押し推力の単位を kN に変更
- 印刷様式を A4横 1ページに収まるよう調整
- 推進管No.自動採番、日時順並び替えに対応
- 切羽土圧 Mpa に対応

## 起動
```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。

## 注意
既存の suishin.db がある場合、起動時に不足カラムを自動追加します。
