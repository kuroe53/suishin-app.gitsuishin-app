# 掘進管理システム 修正版

## 今回の修正
- 印刷時の日付を「日付 + 時間」のみ表示に変更
- 印刷様式の表左側の数字欄を削除
- A4横1枚に全項目（特記事項まで）収まるよう、行高・余白・文字サイズを再調整
- スパン名・管径・推進距離欄の高さを拡大
- 元押し推力の単位は kN
- 推進精度（センター・レベル）と特記事項も印刷に反映

## 起動方法
```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開いてください。

## 印刷設定
- 用紙: A4
- 向き: 横
- 余白: 最小
- 倍率: 100% または ページに合わせる
