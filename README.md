# 掘進管理システム

## 起動
```bash
npm install
npm start
```

Render: Build Command `npm install`, Start Command `npm start`

## 今回の主な追加
- グラフで複数項目を同時表示
- 項目ごとの色選択
- グラフ設定の保存・呼び出し
- 横軸を推進管No./日付から選択
- 横軸表示名を任意設定

- 印刷表の行列サイズを固定
- 1枚あたりの表示データ数を設定可能
