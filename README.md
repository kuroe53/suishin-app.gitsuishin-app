# 掘進管理システム

## 追加機能
- Excel出力（xlsx）
- 日報単位印刷
- 推進管No.範囲指定印刷
- 現場ごとのバックアップ（JSON）
- 入力項目の並び替え、表示/非表示
- 帳票タイトル・項目名・単位の編集
- スマホ・タブレット向け表示調整

## 起動
```bash
npm install
npm start
```
http://localhost:3000 を開いてください。

## Render
Build Command: `npm install`
Start Command: `npm start`


## 滑材注入管理

今回追加した「滑材注入管理」タブでは、日毎・時系列で以下を入力できます。

- 注入管No.
- 注入量 ℓ
- 材料 kg
- 搬入量 kg
- 備考

材料名は画面上で変更できます。変更した材料名は、入力欄・一覧・印刷表に反映されます。

### 自動集計

一覧と印刷では以下を自動計算します。

- 滑材注入量の日累計
- 滑材注入量の全体累計
- 材料使用量の日累計
- 材料使用量の累計
- 搬入量の総搬入量
- 残数量 = 総搬入量 - 累計使用量

### 印刷

「滑材表印刷」ボタンで、時系列に下方向へ進む表形式で印刷できます。
